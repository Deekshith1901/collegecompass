# CollegeCompass Frontend

Next.js App Router + TypeScript + Tailwind CSS frontend for CollegeCompass.

## Setup

1. Copy `.env.example` to `.env.local`
2. Start backend at `http://localhost:5000`
3. Install and run frontend

```bash
npm install
npm run dev
```

## Main Routes

- `/`
- `/colleges`
- `/college/[slug]?id=1`
- `/course/[name]`
- `/exam/[name]`
- `/compare`
- `/rankings`
- `/dashboard`
- `/login`, `/signup`, `/logout`
